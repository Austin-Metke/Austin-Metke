### ⚡ Featured Projects  

- 🕹️ [DMG-J — Game Boy Emulator](https://github.com/Austin-Metke/DMG-J-DEV)  
  A **Game Boy emulator written in Java** featuring Z80 CPU emulation, ROM loading, memory mapping (MBC1), GPU scanline rendering, and an interactive debugger UI.  

- 📊 [Expense Tracker](https://github.com/Austin-Metke/expense_tracker)  
  A **cross-platform mobile app** (Flutter + Firebase) built for a construction company client.  
  ➡️ Employees log expenses, upload receipt photos, and view spending by category with interactive charts. Includes Cloud Functions for backend logic.  

- ☁️ [RESTful API Backend](https://github.com/Austin-Metke/438-Project-2)  
  A **Java backend service** with Spring Boot, PostgreSQL, and Docker containerization.  
  ➡️ Deployed to Heroku with CI pipeline. Includes SQL schema design, integration tests, and Docker Compose for local dev.  

- 📱 [Mobile App (React Native / Expo)](https://github.com/Austin-Metke/438-Project-1)  
  A **cross-platform mobile app** built with React Native, Expo, and TypeScript.  
  ➡️ Features file-based routing, automated testing with Jest, and a modern component architecture.  

- 🎮 [m-overlay — Open-Source Contribution](https://github.com/Austin-Metke/m-overlay)  
  Contributed to **bkacjios' m-overlay**, a controller input overlay for the Dolphin emulator used by speedrunners.  
  ➡️ Added support for several new games by reverse-engineering controller input memory addresses.  

- 🌐 [DynamicDNS-Spigot — Namecheap Integration](https://github.com/Austin-Metke/DynamicDNS-Spigot)  
  Contributed Namecheap DNS support to an open-source dynamic DNS plugin for Minecraft Spigot servers.  
  ➡️ Extended the DDNS service logic and implemented XML response parsing for automated domain updates.
